# 🎯 Конфиген — Профессиональный конструктор конфигураций для Counter-Strike 2

Профессиональный онлайн-инструмент для создания конфигураций Counter-Strike 2.

## 🚀 Возможности
- 🎯 **Конструктор прицела** — стиль, размер, толщина, зазор, точка, прозрачность, цвет RGB
- 🔫 **Viewmodel** — FOV, смещения X/Y/Z, правая/левая рука
- 🗺️ **Радар** — масштаб, вращение, центрирование
- 📊 **HUD** — цвет, снаряжение команды, стиль здоровья
- ⚙️ **Геймплей** — чувствительность, зум, громкость
- 🎮 **Бинды** — jumpthrow, гранаты, очистка декалей
- 🖥️ **Видео** — FPS лимиты, трассеры
- 📡 **Сеть** — rate, interp, cmdrate, updaterate
- 🔊 **Аудио** — mixahead, панорама наушников
- 📱 **Мобильная версия** — адаптивный интерфейс
- 🌍 **Мультиязычность** — русский/английский
- 🎨 **Темы** — тёмная/светлая
- 🔄 **Undo/Redo** — до 50 операций
- 🏆 **Достижения** — 8 наград + конфетти

## ⚡ Быстрый старт
```bash
git clone https://github.com/configen/configen.git
cd configen
open index.html  # macOS/Linux
start index.html # Windows
```
